O propósito desse projeto é juntar a ideia de uma sessão p2prtc com um indexedDB, fazendo cada peer ter sua private key permanente e guardar as piblics keys dos seus amigos, também guardando a configuração dos STUN/TURN servers. No futuro um peer tbm vai guardar a configuração do seu Storage, onde ele vai poder salvar seu Biont pessoal e partilhar com seus amigos por mensagens tipo Whatsapp.
